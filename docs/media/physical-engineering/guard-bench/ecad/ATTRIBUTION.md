# Library attribution

The project uses KiCad 9.0.2. The KiCad Community publishes its symbol, footprint and 3D model libraries under Creative Commons Attribution-ShareAlike 4.0 with the KiCad library exception. Redistributed library items and their modifications retain these terms. The original notices accompany the project in [licenses](licenses/) and in the model archive. [KiCad license and exception](https://www.kicad.org/libraries/license/) · [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

- The local LIS3DH symbol derives from the KiCad sensor library. It names the I²C pins and represents SA0 as an input for the selected mode. The local M2 footprint derives from the KiCad mounting-hole library and uses a 2.30 mm hole. The native project embeds the other standard library symbols and footprints. [KiCad symbol library](https://gitlab.com/kicad/libraries/kicad-symbols) · [KiCad footprints](https://gitlab.com/kicad/libraries/kicad-footprints)
- Four package solids in `models.zip` come from the KiCad 3D library. The resistor, two capacitor packages and 3 × 3 mm LGA carry the original contributor notices in their STEP headers. [KiCad 3D models](https://gitlab.com/kicad/libraries/kicad-packages3D)
- The JST solid is an original dimensional reference derived from the JST drawing and the selected footprint. It represents the body, mouth, hold-downs and contacts at their positions for virtual fit checks. Compare the received connector and cable before qualifying the interface. [JST SH drawing](https://www.jst-mfg.com/product/pdf/eng/eSH.pdf)

The native recorder circuit and enclosure, guard fixture and aircraft revisions are project contributions. See the [repository license](../../../../../LICENSE).
