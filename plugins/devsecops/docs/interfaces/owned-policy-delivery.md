# Canonical policy Git delivery

The fixed operations caller invokes owned_policy_delivery.execute_policy_delivery for primary/replay inject, primary/replay deliver, and reset. The producer consumes the original qualified runtime policy plan, an authenticated checkout of the actual predecessor delivery, the frozen source mapping and tools, and—only for correction—the original accepted and independently validated native patch. Saved JSON cannot issue any of these origins.

The supported canonical source is an explicitly selected Helm values scalar. Its semantic source diff must be exactly the selected JSON pointer. Pinned Helm and kubeconform render every profile target. The full rendered inventory and every image must remain identical except the actual qualified policy selector, and that policy must equal the original experiment's complete before/after object. Correction is applied in a private source copy and must reproduce both the original validator's patched-tree manifest and its exact render pair. Native Git then prepares the full-tree-preserving single-file commit and complete object transport.

Reset compares the current head with the original delivered baseline and rejects unrelated changed files. It restores only the owned source path. When those bytes already match, it creates an explicit sole-parent same-tree reset marker and reports content_already_baseline=true. This is an actual Git delivery with a fresh observed watched revision, not a fabricated patch or a runtime rollback assertion.

Actual separate reader credentials observe the current Git base; the original Developer writer pushes once, and the separate owner merge-request actor checks required jobs and performs one source-pinned fast-forward merge. Each action remains bound to its current phase and grants. Completed receive/readback origins are historical observations: expiry of the old receive-base capability cannot invalidate them, and cannot authorize another write. The fresh MR gate and current operation admission authorize the next operation.

Delivery evidence includes the selected source tree (verified by the native commit), rendered SHA, original native request SHA where applicable, actual Git commit/tree/parent, and observed_at after final watched-branch readback. The native commit ID is retained before any MR wait so no expired preparation capability is re-admitted afterward.

Local tests execute actual native Git, Helm and schema validation, including inject, native-correction consumption, and reset. Lifecycle/F0/model/remote boundaries are explicitly controlled where stated. This does not prove a live E2E run, repeated recovery, recording, or playback. D3 extension mutation remains a separate interface; this closed producer cannot write arbitrary platform files.
