# Optional comparison weighting

Report unweighted results by category and reasoning band first. Difficulty
estimates should remain visible rather than disappearing into one number.

If the user needs a weighted secondary result, one simple policy is L/M/H = 1/2/3:
average repetitions per task, weight tasks within each category, then average
categories equally. These are policy weights, not measured difficulty ratios.

Freeze labels, weights and membership before running the comparison. Calibrate
later against repeated success and resource observations from a fixed baseline.
Keep missing trials visible. Weighting does not turn an invalid trial into a
score or compensate for a failed required criterion.
