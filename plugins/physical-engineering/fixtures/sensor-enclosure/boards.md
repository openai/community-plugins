# Sensor board mechanical interface

| Feature | Design value |
| --- | --- |
| Substrate | 34 × 22 × 1.6 mm with rounded corners |
| Mounting holes | Four Ø2.30 mm clearance holes on a 28 × 16 mm rectangular pattern |
| Mounting plane | Underside at Z = 5.0 mm above the base datum |
| Component allowance | The tallest modeled package reaches Z = 8.8 mm |
| Lid | Underside at Z = 15.0 mm |
| Fasteners | Four M2 × 4 mm screws through the PCB into the integral base posts |

The STEP assembly includes the substrate, a sensor package, a shield and six contact pads. Their positions define a reference board envelope for the enclosure. An electrical design, fabrication files and measured thermal or airflow performance would require a separate board design and prototype.
