# Synthetic healthy project

## Commands

- `npm install` installs dependencies.
- `npm run build` builds the project.
- `npm test` runs the test suite.
- `make check` runs the same tests through make.

## Layout

- Entry point: `src/index.js`.
- Design notes live in [the architecture doc](docs/architecture.md).

## Conventions

- Keep each module under 300 lines and export one public function per file.
